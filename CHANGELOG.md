All notable changes to Reverse Engineering Toolkit will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-09-22

### Added
- 📋 **PE Analyzer** - Full PE file format analysis (DOS/PE headers, sections, imports, exports)
- 🔢 **Hex Editor** - Binary file viewer and editor with pattern search
- 🧠 **Memory Scanner** - Process memory scanning and modification
- 🔍 **Pattern Scanner** - Byte pattern search with wildcard support
- ⚙️ **Disassembler** - Built-in x86/x64 disassembly engine
- 🌐 **Network Monitor** - Process network connection tracking with DNS resolution
- 🌍 **Bilingual UI** - English and Russian language support with real-time switching
- 📝 **Localization System** - Custom implementation with 500+ translation keys
- 🎨 **Dark Theme** - VS Code-style dark interface
- 📦 **Standalone Build** - No external dependencies required

### Technical
- .NET 8.0 WPF application
- Windows API integration via P/Invoke
- MVVM-like architecture with data binding
- Custom localization with XAML converter
- Administrator rights support for privileged operations
